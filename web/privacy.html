Le contenu de vos relevés (transactions, soldes, montants) n'apparaît dans aucune de ces lignes de conservation longue : il n'est jamais écrit en base. C'est la différence structurelle entre un convertisseur de fichiers et un agrégateur bancaire.

Sous-traitants et localisation

StatementFlow ne délègue qu'un petit nombre de fonctions, à des sous-traitants connus :

  • Render (render.com) — hébergement de l'application et de l'API, région Oregon, États-Unis (vérifiable par DNS : gcp-us-west1). Les fichiers ne font qu'y transiter en mémoire.
  • Supabase (supabase.com) — base de données PostgreSQL, région Francfort, Allemagne (eu-central-1, UE). Y vivent : comptes, clés hachées, crédits, métadonnées d'historique.
  • SasPay (saspay.me) — passerelle de paiement de l'achat de crédits. Ne traite que les données nécessaires à la transaction.
  • GitHub — dépôt de code public.

Il n'y a aucun autre destinataire : pas de régie publicitaire, pas d'outil d'analyse tiers, pas de revente. La base de données étant hébergée dans l'Union européenne et les documents n'étant jamais stockés, les données personnelles persistantes restent en UE ; seuls les traitements éphémères (quelques secondes, en mémoire, purgés au TTL) passent par les États-Unis.

Vos droits et comment les exercer

Vous disposez des droits d'accès, de rectification, d'export, d'effacement et d'opposition sur vos données de compte. Concrètement :

  • Export : vos historiques de conversion (métadonnées) sont téléchargeables depuis le tableau de bord ;
  • Suppression : demandez-la via le contact des mentions légales — email, clés, historiques et métadonnées sont effacés sous 30 jours ;
  • Effacement immédiat des relevés : inutile de le demander — il est déjà effectif (TTL 15 minutes, aucune copie nulle part) ;
  • Portabilité : le format JSON des résultats est documenté sur la page API.

Les écritures financières agrégées (montants encaissés, packs vendus) sont conservées de façon anonymisée pour les obligations comptables, sans lien avec votre identité.

Base légale et honnêteté

Les données de compte sont traitées sur la base de l'exécution du contrat (créer et gérer votre accès). Les événements commerciaux le sont sur la base de l'intérêt légitime (mesurer l'usage du service), sans tracker tiers.

Honnêteté : StatementFlow n'est pas certifié RGPD ni audité par un tiers, et l'éditeur n'est pas encore immatriculé — voir les mentions légales pour l'état réel. En revanche, chaque traitement décrit ici correspond à une ligne de code vérifiable dans le dépôt public, et l'architecture (rien de bancaire en stockage) rend les violations de confidentialité structurellement limitées.
