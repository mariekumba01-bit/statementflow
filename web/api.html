API StatementFlow

Chaque compte dispose d'une clé API personnelle (visible dans le tableau de bord, régénérable). Le moteur et la facturation sont identiques à ceux du tableau de bord : 1 crédit ≈ 1 page PDF ou 50 lignes de tableau, aucun débit si le traitement échoue.

Principe

  1. POST /v1/analyze avec votre fichier (multipart) et l'en-tête X-API-Key → un job_id (HTTP 202).
  2. GET /v1/results/{job_id} avec la même clé → statut processing (202), puis le résultat JSON complet (transactions + contrôles comptables).
  3. Les crédits sont réservés puis réglés automatiquement ; en cas d'échec d'analyse, la réservation est restituée.

Les résultats restent récupérables 15 minutes (TTL), uniquement avec la clé ayant soumis le fichier. La spécification OpenAPI complète est servie sur /docs.

Python

import requests, time

API = "https://statementflow-api-ch0f.onrender.com"
KEY = "sf_votre_cle"          # tableau de bord → clé API

with open("releve.pdf", "rb") as f:
    r = requests.post(
        f"{API}/v1/analyze",
        files={"file": ("releve.pdf", f)},
        headers={"X-API-Key": KEY},
    )
r.raise_for_status()
job = r.json()["job_id"]

while True:
    res = requests.get(f"{API}/v1/results/{job}",
                       headers={"X-API-Key": KEY})
    if res.status_code == 202:
        time.sleep(2); continue
    res.raise_for_status()
    break

data = res.json()
print(data["usage"], data["billing"])
for tx in data["transactions"][:5]:
    print(tx["date"], tx["label"], tx["amount"])

JavaScript (Node 18+)

const API = "https://statementflow-api-ch0f.onrender.com";
const KEY = "sf_votre_cle";

const file = await fs.openAsBlob("releve.csv");   // Node 20+
// ou : const file = new Blob([await fs.readFile("releve.csv")]);

const form = new FormData();
form.append("file", file, "releve.csv");

const submit = await fetch(`${API}/v1/analyze`, {
  method: "POST", headers: { "X-API-Key": KEY }, body: form,
});
const { job_id } = await submit.json();

let data;
for (;;) {
  const res = await fetch(`${API}/v1/results/${job_id}`, {
    headers: { "X-API-Key": KEY },
  });
  if (res.status === 202) { await new Promise(r => setTimeout(r, 2000)); continue; }
  data = await res.json(); break;
}
console.log(data.usage, data.billing);

n8n (workflow d'intégration)

  1. Nœud HTTP Request — Method: POST, URL: https://statementflow-api-ch0f.onrender.com/v1/analyze, Authentication: Header Auth (nom X-API-Key, valeur = votre clé), Body Type: Form-Data (Binary), champ file ← Binary → Data (données du nœud précédent, ex. lecture d'email ou de Drive).
  2. Nœud Wait — 3 secondes.
  3. Nœud HTTP Request — Method: GET, URL: https://statementflow-api-ch0f.onrender.com/v1/results/{{$json.job_id}}, même Header Auth.
  4. Nœud IF — si {{$json.status}} vaut processing, reboucler sur le Wait (ou activer « Retry On Fail » avec 10 essais / 5 000 ms d'intervalle) ; sinon continuer.
  5. Les transactions ({{$json.transactions}}) alimentent votre base, Google Sheets, etc.

Conseil : en cas de réponse 202, n8n « Retry On Fail » sur le nœud 3 suffit souvent à remplacer la boucle Wait/IF.
